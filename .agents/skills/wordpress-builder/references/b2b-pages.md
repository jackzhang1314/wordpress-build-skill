# B2B 外贸站：按页面任务实施

页面结构确定前，按 [search-quality.md](search-quality.md) 写明该页的买家任务、独立价值、证据与下一步；没有独立价值的关键词页不机械新增。

建完整 B2B 站时先确定企业、产品、目标买家、市场/语言与事实来源，再制定逐页内容与设计。页面可以有不同的内容组织与交互，但共享主题、设计 token、业务模型、媒体和链接来源。

## 页面决策

| 页面 | 买家需要完成的事 | 默认实现与数据归属 | 核心验收 |
| --- | --- | --- | --- |
| 首页 | 判断供应商与自己是否匹配，进入产品或应用 | front-page.html 承接首页正文；核心块/起始 Pattern + 定制样式；品牌呈现字段归主题，产品/方案模块查询真实对象 | 首屏说明产品/服务范围与适用买家；入口准确；所有信任证据有来源 |
| 产品详情 | 核对适用性、规格、交付条件并发起询价 | 业务插件产品 CPT + 原生 customTemplates/默认 single 模板 + 必要 PHP 动态模块；原生标题/摘要/正文/主图，ACF 保存结构化规格、附件 ID 和关联对象 | 参数有来源；图集/资料真实；询盘携带产品 ID；未知参数不编造 |
| 产品分类 | 缩小选型范围并比较同类产品 | 真正的产品 taxonomy + taxonomy 模板；分类说明与选型信息用 term 字段；服务端筛选/分页 | 刷新和分享 URL 保留筛选；分页不重复；空结果能重选；筛选项来自实际数据 |
| 行业解决方案 | 从工况/问题找到可行方案和产品 | 少量独立方案可用 Page + 指定模板；需要统一归档、关联产品/案例或持续扩展时用 solution CPT + 专用模板 | 场景、选型约束、方案和证据相互对应；关联内容使用对象 ID，不复制产品参数 |
| About Us | 判断企业角色、能力和合作可信度 | 专用 Page 模板；故事与说明用原生内容，确有复用需求的证据对象另建模型 | 明确制造商/贸易商/服务商身份；工厂、团队、认证、客户证明真实且有使用授权 |
| 联系/询盘 | 提交足够明确的采购需求 | Page + 成熟表单插件；字段依采购流程确定；联系人、产品和方案上下文可回读 | 必填/失败/成功路径成立；后台留存；生产通知送达另验；不要求无关个人资料 |
| 资料/文章 | 获得选型知识和可下载文件 | 原生文章/分类；需要结构化资料库时另定义文档对象 | 内容可编辑；下载文件有效；产品/方案引用正确；无虚假技术结论 |

首页和 About Us 的布局不必复用产品详情的模块排列。产品详情重视参数与选型，分类页重视检索密度，方案页重视场景与解决过程。不要机械为每页放同一个大横幅和三列卡片。

## 实现选择

- 同一原生区块主题内，各页可组合核心块、Patterns、定制 CSS 与 PHP 动态模块。产品模板和 ACF 属于不同层，正常共用。特殊整页 PHP 要明确路由与编辑限制；现有经典 PHP 基线不自动迁移。
- 按 [seo.md](seo.md) 输出服务端核心内容、真实链接和可抓取分页；分类/方案提供独立选型内容，不批量复制参数或无价值关键词页面。
- 编辑性强的文章/品牌叙事优先原生内容。需要跨页查询、筛选或保持一致的数据使用业务字段或关联对象，不重复埋进 HTML。
- 有限的重复资料先核对 ACF 免费版边界；不能默认生成依赖 Repeater/Gallery/ACF Blocks 的 PRO 方案。需要 PRO 时明确实际能力和授权，或采用原生附件/子对象等适用模型。
- 动态表格、筛选、图集等交互按真实需求实现；简单链接、锚点或服务端筛选足够时，不增加常驻应用框架。
- 询盘的产品/方案上下文使用稳定 ID，并在服务端核对公开对象；买家可见名称另作展示。页面链接由对象 permalink 生成，不能依赖固定域名或标题。

## 设计与验证顺序

确认资料后先形成站点地图、买家路径、各页主动作和素材清单。建立有行业依据的设计方向，然后实现首页、一个代表性产品页和一个分类页，实看桌面与移动端，再扩展方案和品牌页。

逐页验证真实 WordPress 输出、编辑保存、图片和下载、关联链接、键盘操作及移动布局。完整询盘链在最终页面验证；截图或审美评分不能替代业务功能。资料未到位时可推进模型和模板结构，但不能把虚构样板当作已确认的客户网站。

## 使用已有网站作设计参考

用户指定的参考站默认提供视觉、信息架构与页面布局输入；除非明确要求采用其技术栈，不改变已选择的 WordPress 渲染和内容模型。可读取部署代码提取布局、色彩、路由和素材引用，但不能把整站 bundle 嵌入 WordPress 后称为可编辑实现。

逐项检查图片实际 MIME、表单是否真的提交、联系方式与声明的来源；HTTP 200 不等于图片有效，成功提示不等于询盘入库。示意素材的署名与许可保留，内容待核实时将交付标记为预览。询盘上下文 ID 使用隐藏字段和服务端对象校验，买家看到的是产品名称。
