# Starter Versus Existing

Starter is a fast, opinionated path for new B2B sites. It is not the only supported project type.

Use Starter when the user wants a ready B2B architecture and accepts the Starter contracts.

Use generic source when the user owns a custom implementation and wants controlled local deployment.

Use external when WordPress already exists and local ownership of code is not established.

Never copy Starter over an external or custom site without explicit authorization, backup and source-custody migration.
