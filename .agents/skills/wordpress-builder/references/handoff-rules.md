# Handoff Rules

Handoffs are one-way unless the task changes.

```text
Setup -> Content/Design/Delivery
Content -> Delivery
Design -> Content/Delivery
Delivery -> Recovery or Router
```

Do not load another skill unless the task crosses its boundary.

Every handoff should state:

1. completed work;
2. changed files/remote data;
3. project mode;
4. verification evidence;
5. next skill;
6. unresolved risks.
