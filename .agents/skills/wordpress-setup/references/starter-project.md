# Starter Project

Use Starter only as a fast path for a new B2B site:

```bash
node wordpress-builder.mjs init <project-name> --root ../projects --from-starter
```

Starter projects use `sourceProfile: starter` and keep Starter route, ACF, component, form and media contracts.

For custom source projects, use `sourceProfile: custom`; do not force Starter templates or components.

Plugin baseline details are in [../../wordpress-content/references/content-model.md](../../wordpress-content/references/content-model.md) and the Hostinger setup reference.
