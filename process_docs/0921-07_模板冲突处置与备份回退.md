- 新增 `examples/b2b-block-starter/scripts/template-resolve.mjs`（npm run starter:template-resolve）三种显式处置：

  - `reset --backup OUT.json PATH...`：先把覆盖完整内容写入备份 JSON，再删除覆盖让新文件生效；删除前逐一复核内容哈希，拦截「预检到处置之间覆盖又被编辑」；任一路径无覆盖则整批拒绝，不做部分处置；theme.json 全局样式明确拒绝。
  - `restore BACKUP.json`：从备份重建覆盖并校验当前主题与内容哈希；目标路径已有覆盖时拒绝，避免歧义覆盖。
