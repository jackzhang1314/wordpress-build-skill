# 0924-04 空站表单自动创建

- 时间：2026-09-24 18:45 Asia/Shanghai
- 触发原因：真实空站部署前审查发现 Starter 内容使用 `[starter_rfq_form]`，但旧逻辑硬编码 Fluent Forms ID 3；全新站点没有该表单。
- 主要工作：
  - Starter 插件新增 `ensure_rfq_form()`，首次渲染时自动创建“Request for quotation”。
  - 表单字段包含姓名、工作邮箱、公司、国家、产品/项目类型、需求、联系同意。
  - 表单通知默认发送到 WordPress admin email；后续可由 SMTP mu-plugin 发出。
  - `starter_rfq_form_id` option 记录表单 ID；若 option 丢失，会按标题幂等恢复。
  - 短代码不再硬编码 ID 3。
- 验证：
  - Starter 测试 134/134 通过。
  - Harness check 全绿。
- 遗留：
  - 新空站部署后仍需提交询盘并检查 Fluent Forms 日志/邮件。
