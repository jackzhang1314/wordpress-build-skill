## 4. 实测坑速查表（全部已验证，细节在 references/theme-code.md）

1. 区块模板优先级永远压过 PHP fallback → 用 PHP 模板必须删同层级 `.html`。
2. 首页：`get_front_page_template()` 只认 `front-page.php`，忽略后台自定义模板设置（REST 写入返回成功但前台不生效）→ `front-page.php` 委托页方案。
3. `get_header()` 不解析 Block Theme parts → 必须 `block_template_part()` + 手动 `wp_head()/wp_footer()` 完整文档壳。
4. Block Theme 不自动启用 `title-tag` → 漏了全站无 `<title>`（P0 级 SEO）。
5. ACF 图片字段：REST GET/写都是附件 ID；`get_field()` 前台自动转 URL；REST 写 URL 字符串被 400 拒。
6. WP 6.9 `render_block_core_shortcode` 只做 wpautop 不执行 do_shortcode → 部件内 shortcode 块原样输出（生产修复一行 filter；footer 已改静态规避）。
7. Playground 三坑：worker 文件系统是启动快照（部件改动后必须整进程重启）、进程会静默退出（000 断连，会话式 PTY 启动保活）、SQLite 在 `wp-content/database/.ht.sqlite` 可直查。
8. 对比度：品牌亮橙 3.6:1 不达 AA → `--tl-signal-text`（#C9430A，4.9:1）用于按钮/小字。
9. 特异性：`.entry-content h2.wp-block-heading` 0,3,0；`.tl-main .wp-block-post-title` 宽选择器污染卡片标题 → `>` 直接子级。
10. PHP 语法：`foreach as [$a,$b]` 合法、`as array(...)` 非法；无 php-cli 时靠前台状态码 + `wp-content/debug.log` 定位。
11. 凭据卫生：`.lab/artifacts/connection.json`（gitignored）；仓库敏感串扫描 0 命中。
