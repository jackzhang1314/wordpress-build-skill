# 0919-001 原创机械工业风 UI 重构

## 时间与触发

2026-09-19 03:55 Asia/Shanghai。用户反馈此前站点整体难看，并明确可以不使用参考站素材，但希望先构建样板站。判断此前实现缺少设计层，只验证了 CMS 结构和 REST 链路。

## 主要工作

- 新增原创 WordPress Block Theme `TerraLift UI`，建立工业机械设计系统、header/footer、页面模板和产品/案例详情模板。
- 修改 `catalog` 区块编译器，使 Query Loop 输出 featured image。
- 首页和 Equipment 页目录刷新为图片卡。
- 为 6 个产品分配 CC0 featured images。
- 创建 3 条 `oct_case` 应用示例、专用 case template 和 Case library 页面。
- 更新 header/footer 导航，加入 Cases。
- 用浏览器复查桌面、手机、H1、横向溢出、深色面板文字对比度、图片加载和站内链接。

## 遗留

- 仍不是参考站像素级复刻，也不应作为版权素材复刻交付。
