# 0924-07 UI 导航与组件优化

- 时间：2026-09-24 21:50 Asia/Shanghai
- 触发原因：用户指出分类页面包屑纵向编号显示，且主导航缺少 Products → 分类/详情的信息架构。
- 根因：
  - Breadcrumbs 组件输出语义 `<ol>/<li>`，但 CSS 未重置列表编号和纵向流向。
  - Seed 只创建一层导航；`wp_nav_menu` 也限制为 `depth:1`。
  - 缺少 UI 组件契约门禁，导致“组件有 HTML、CSS 没配套”“导航有页面但缺层级”这类问题未被本地拦截。
- UI/IA 修复：
  - Breadcrumbs 改为横向 `Home / Products / Current`，当前页加粗。
  - 主导航扩展为两层级：
    - Products → Industrial / Outdoor / Commercial Indoor / Food-grade & Washdown。
    - Industries → 3 个行业方案。
    - Knowledge → 3 篇采购指南。
  - 桌面端 submenu 使用 hover/focus-within；移动抽屉内子页缩进展示。
  - Header 增加 Request a quote CTA；移动端保留紧凑 CTA。
  - Breadcrumb、card chip、product placeholder、trust strip、search 表单、Fluent Forms 按钮样式优化。
  - 首页无 Customizer 统计时自动回退工厂统计。
  - 分类页重复简介、About/Guide 页 hero 与正文重复文案已消除。
  - CTA band 的主要操作从文本链接升级为 button。
- Harness 沉淀：
  - 新增 `ui-component-contracts` 门禁：breadcrumb list reset、导航层级、submenu CSS、导航可访问性。
  - `verify` 新增空媒体 Starter 的远端附件数量校验。
  - 新增 screenshot 69 张全量证据流程。
- 验证：
  - typecheck、lint、138/138 tests、starter harness check 全绿。
  - 线上 23 页全部 200；每页 H1=1；0 heading skip；remote blank media 0。
  - 线上首页导航含 3 个 submenu、4 个产品分类、3 个行业子页、3 个指南子页。
  - 分类页 breadcrumbs HTML/CSS 确认为横向，主题 CSS 6.1.2 已生效。
- 提交：
  - `fix(starter): add hierarchical navigation and ui contract gates`
