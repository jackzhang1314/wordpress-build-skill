时间：2026-09-22 02:27 +08:00（Asia/Shanghai）。
触发：①私有仓库同步完成后，按既定顺序执行②补全增量传输的最后两块。

## 主要工作

1. **二进制校验闭环**：两个字体经公网 URL 下载哈希核对与本地一致（0921-02 的「未验二进制」缺口关闭，当时仅 API 文本通道可读）；`incremental-deploy.mjs` 主题模式收敛后自动对 unverified 二进制做公网哈希核对并记入 verifiedBinaries。
2. **插件模式**：`theme-diff.mjs` 抽出通用 `dirInventory(root,markers)`（themeInventory 委托 theme 标记）；`theme-baseline.mjs` 加 KIND/ROOT 参数（plugin 身份标记 site-model.php，远端根 wp-content/plugins/site-model）；`incremental-deploy.mjs --plugin` 走同一门禁链（无模板覆盖门）。
3. **远端读取边界处理**：凭据类文件被托管 API 拒绝读取（settings.php 实测「This file seems to hold sensitive credentials」）→ 按 unverified 处理不进变更集；内容接口偶发空 path JSON 异常响应（退出码 0）→ 形状校验+三次退避重试；错误分类同时检查 stdout/stderr/message（CLI 错误信息可能在 stdout）。
4. **no-op 成功态**：0 变更是收敛成功而非断言失败——无变更时跳过备份/上传/清缓存，直接输出收敛报告正常退出。

## 实际失败与修复（全保留）

1. settings.php 敏感拒绝崩溃两轮：第一轮错误分类只查 stderr/message（消息在 stdout）→ 修正三通道检查；第二轮暴露块读取 async 回调内非法 continue → 改 return。
2. 内容接口偶发空 path JSON 响应（退出码 0 的服务端抖动）→ 形状校验加入有界重试。
3. theme-diff 重构时误删 `await walk()` 导致 files 恒空（"identity file missing" 级联 5 个测试失败）——恢复调用后全绿；教训：重构标记检查时不得顺手改动遍历调用行。
4. no-op 语义修正前，插件模式首次实跑以断言失败退出（actual 0 changes）——属设计失误非环境问题。
