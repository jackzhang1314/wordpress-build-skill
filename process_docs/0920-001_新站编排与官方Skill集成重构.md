# 新站编排与官方 Skill 集成重构

时间：2026-09-20T00:13:52+08:00（Asia/Shanghai）。

## 触发与范围

用户要求将方案重构为整合官方及优秀开源能力的总编排，并明确本阶段仅新建站，不接管旧主题或 Elementor 站点。保留本方案创建站点的维护能力。当前版本 0.3.0；基准 HEAD a49821fa88311b5fa59f4d0298b8a6f5b71bd7a1。工作区包含前轮未提交修改，本轮没有提交、推送或生产发布。

## 主要工作

- 将 10 个 WordPress 官方模块及其依赖文件随 Skill 固定分发，66 个原始文件保持上游内容，附许可证与 SHA256 清单。来源提交 d87ee6916e740c7960b6959220c0481a41b320c7。
- 新增 capabilities、project-init、project-inspect、project-record、project-status；实现新站契约、官方本地 triage 执行、阶段依赖和证据漂移检测。记录不等于远端验收或发布授权。
- 重写 Skill 总入口、架构、编排、主题、阶段与运行说明；README 与 docs/ARCHITECTURE.md 描述实际实现。01–16 号文档标记历史，18 号规划按新站范围修订，保留历史证据。
- 构建时校验上游文件；整个 Skill 包可移出仓库运行。专业模块按需加载，未增加动态调度服务器。
- 新增独立干净 WordPress 集成夹具，不复制演示数据库。业务模型归插件，主题负责显示，验证 ACF 更新后前台输出。

## 验证结果

- npm run typecheck、npm run lint、npm test：通过，31 项工具测试（原有 27 项加编排 4 项）。
- npm run build：通过，并验证 10 个固定模块完整性。
- Skill 格式校验通过；当前自维护文档相对链接、git diff --check 通过。
- 完整 Skill 复制到临时目录后，capabilities → project-init → 官方 project-inspect → discover 回执 → project-status 通过，下一阶段为 model，不依赖 WordPress 凭据。
- npm run test:new-site：8 项通过；实测 WordPress 7.1.1 / PHP 8.3.32 / ACF 6.8.9。覆盖无演示产品、经典主题、ACF、字段读写及更新、正文保留、REST 模型和模板输出（包含更新后的字段值）。最后增强模板输出断言后单独通过脚本 lint 与集成复跑。
- 初次 triage 测试夹具的主题头格式不合规范，修正为常规多行头后通过；没有修改官方脚本。初次 WordPress 目标 7.1 实际返回 7.1.1，已改为精确目标并校验实测版本。

## 边界与后续

本轮完成编排基础及最小真实新站链路，未完成完整企业站浏览器交付。只有官方 triage 被 CLI 自动执行并验证；其他模块是可加载的专业工作流，不宣称全部完成行为测试。PHP 与区块路线的同 Brief 对照、生产邮件、主机部署与恢复、第二行业完整站点仍待实测，不能宣布某路线为普适最优。Studio 与 Respira 仍为研究来源，未启用。
