# Harness v2 project contract

The central CLI is this repository's `harness/cli.mjs`; it operates on any directory containing a valid `project.json`. The production scaffold is created by:

```bash
node harness/cli.mjs init <project-name> --root /path/to/projects
```

A deploy-ready project supplies:

- `project.json`: domain, theme/plugin slugs, main plugin file, SSH, required plugins, media sources, live pages, content markers and expected content counts.
- `theme/`: classic PHP theme with `style.css`, `functions.php` and `index.php`.
- `plugin/<plugin-main>.php`: CPTs, taxonomies and ACF local fields.
- `docs/media/*/`: real project media configured through `project.json`.
- Optional `scripts/seed.php` + `content/site-data.json` when `seed.enabled` is true; `content/media-map.json` is generated by `media`.

The seed contract is deliberately project-specific: a project may own its business shape, while the harness owns preflight, transport, activation, cache, verification, rollback and state. Never hardcode a project name, domain or content model in the central CLI.
