# Equipment Studio：整站重设计与转化验收

2026-09-20，Asia/Shanghai。本轮目标是重做 9490 的界面、页面信息结构、导航与询盘入口，保留已选定的原生 WordPress 组合架构。源项目见 [项目说明](../../../examples/b2b-block-starter/README.md)、[设计规划](../../../examples/b2b-block-starter/DESIGN.md)。旧的技术骨架证据保留在 ../b2b-block-starter/，不替代本轮证据。

## 已实现

17 个原生模板、9 个业务动态块、自托管字体与新配色。首页、设备目录/分类、标准和叙事产品详情、应用目录/详情、About、采购指南/文章、联系页及辅助页采用不同结构。主要页面正文仍在 WordPress 中编辑，产品/分类继续通过 CPT、ACF 和原生模板选择维护。

真实 Navigation 菜单提供设备与五类子菜单、应用、指南、About、Contact；桌面报价按钮和产品按钮打开当前页弹窗。首页可直接填写。每页一个 Fluent Forms 实例，弹窗移动该节点，关闭保留输入，恢复焦点；产品 ID 继续在服务端校验。真实 href 可退回联系页。

## 本轮验证

- `functional.json`：primary/reuse 两个现有独立 MySQL 环境上源码/分发哈希、REST、ACF Query Loop、两套模板切换、分类布局、新建草稿/发布/回收、分页、12 个 PHP 文件语法及数据库模板覆盖检查。
- `browser.json`：实际编辑器模板选择、ACF 输入与 Save、正文/主图保存、首页编辑和 Pattern 插入、分类后台下拉框与保存；17 模板、2 部件、首页和 3 个 Pattern 块解析有效。主图通过原生 editor data action 加实际 Save 验证，不声称点击过媒体选择器。
- `design-check.json`：11 类代表页面 × 1440/768/390 = 33 组检查，无水平溢出、无失败图片、一个主 H1、每页一个表单。另测手机菜单、原页弹窗、产品上下文/通用入口清空、输入保留与焦点恢复。
- `routes.json`：65 条公开内容/分类/归档 URL 为 200、主 H1 唯一、有导航、有表单、无 PHP 错误且保留 noindex。
- `seo.json`：8 类路径的 title/description/canonical/robots、真实 sitemap 产品与分类收录、筛选/搜索/作者页策略。本地短暂模拟公开索引设置，finally 恢复 noindex；不代表 Google 实际收录。
- `enquiry.json`：联系页四项必填、伪造产品 ID 拒绝、正确产品关联、1 个真实条目与 1 封 Mailpit SMTP 邮件。
- `conversion.json`：390px 首页内嵌与产品弹窗各提交一次，共 2 个条目、2 封 SMTP 邮件，产品弹窗关联正确。
- 仓库 `typecheck`、`lint`、35 项测试及 `build` 通过。字体许可随源码保留；49 个主题/插件文件分发打包。实际源码版本见 `source-state.json`，不是仅引用 Git HEAD。

实际检查桌面首页/产品/目录/应用/About/弹窗及手机菜单/表单截图。修复了 Fluent Forms fieldset 导致表单半列宽、移动分类链接误隐藏、重复应用照片卡片、规格纵列造成的大面积留白。最终截图等待字体和菜单动画结束，后台临时验证文字恢复后采集。`home-first-pass.png` 保留首次表单布局问题，其余 `*-1440.png` / `*-390.png` 是新版页面证据。

截图不是审美评分；本轮完成设计实现和技术验收，不宣称已经取得用户视觉认可。仍可改进的真实素材问题是产品图片重复、含其他厂商标识，当前只作有来源的演示图片；mock 规格与文字不能用于真实商业承诺。

## 边界与复验

旧版站点未删除或迁移；9491 是模型复用夹具，不是完整设计后的泵网站。本轮未做生产部署、外部邮箱送达、生产恢复或重新创建整个 Docker 环境；此前干净安装证据保留。新启动脚本已接入新版 seed，最新受控内容迁移在现有 9490 实跑并备份数据库。

源码同步不自动覆盖编辑过的正文。`starter:design` 是受保护的演示内容重建命令，会备份并改写 9490 演示内容，不应用于客户编辑。后续回归将后台变更测试与最终截图串行执行，避免临时文字污染截图。
