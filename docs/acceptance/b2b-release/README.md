# 原生区块发布包与隔离安装验收

最新通过：[报告](run-Lpa0jf/report.json)、[浏览器询盘](run-Lpa0jf/browser.json)、[执行源码状态](run-Lpa0jf/source-state.json)。2026-09-20，Asia/Shanghai。

从既有 9490 读取快照，在隔离准备库去除源账号/应用密码、询盘、日志和队列，通知默认关闭；再生成完整私有 tar.gz、SQL、插件清单与逐文件哈希。空白安装与恢复环境只从归档复制代码/媒体，不挂载站点源码，也不运行 seed；测试工具与 SMTP 配置由验收环境单独提供。

结果：3359 个归档文件；安装及恢复各验证 3357 个运行文件哈希、6 个附件和 7 条路由（含 404）。四个必装插件版本及激活状态通过。ACF model 字段修改回显、两套产品模板切换通过。首页与产品弹窗共 2 次实际浏览器提交、2 条数据库记录、2 封新增 SMTP 通知，核对收件人及提交邮箱。恢复到独立数据库/文件卷，11 张内容与表单表逻辑哈希一致，保留 2 条询盘；重建 Web 容器后逻辑状态保持。

两套目标数据库位于同一个隔离 MySQL 服务，不是跨服务器灾备演练。当前只验 model 字段和产品模板的程序化编辑，不等于本轮重新验收后台所有 UI、视觉、全部 SEO 或性能。WordPress 7.1 / PHP 8.3.33 / MySQL 8.4.11。完整包包含演示资料，仅用于当前参考项目，不是任意客户数据库的通用脱敏器；不对外发布 SQL 或媒体归档。

复验：`npm run test:starter:release`。需现有 9490、Docker、Playwright CLI，端口动态分配且仅 loopback。过程失败不会更新最新包指针，本次服务结束即停止，卷及失败证据保留。私有成功指针为 `.lab/b2b-release-latest.json`，其 run 目录有 site.tar.gz、manifest.json、release.json；不包含在公开证据中。
