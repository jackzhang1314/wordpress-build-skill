# 原创机械工业风 UI 重构

2026-09-19 03:55 Asia/Shanghai。根据用户反馈，本轮停止在默认视觉上继续堆页面，转向补齐缺失的“设计层”。参考站仍只用于高层业务结构理解；没有复制其 logo、图片、文案、CSS、HTML、配色、字体组合或精确布局。

## 结论

当前默认视觉差的根本原因不是 WordPress 原生区块，而是此前实现只覆盖了 CMS 结构链路，没有覆盖设计系统。原页面使用默认主题内容宽度、默认排版、默认按钮，并且 section 缺少高级布局属性，所以看起来像文档而不是机械外贸官网。

本轮新增 `TerraLift UI` 原创(block theme)，并重构核心页面视觉。

## 设计系统

### 色彩

| Token | Hex | 用途 |
| --- | --- | --- |
| Base | `#F4F6F7` | 页面底色 |
| Surface | `#FFFFFF` | 卡片和面板 |
| Ink | `#10222A` | 主文字、深色面板 |
| Steel | `#455A64` | 次级文字 |
| Signal | `#F26B21` | 主行动色、强调线 |
| Safety | `#FFC629` | 工业安全色、细节强调 |
| Concrete | `#E1E7E8` | 浅色分区 |
| Line | `#C3CFD2` | 分隔线 |

### 字体

- Display：Ysabeau Office Variable，用于标题、站点名、卡片标题。
- Body：Fira Sans，用于正文和导航。
- Technical：Fira Code，用于顶栏、表头、footer 小字。

### 布局

- 正文宽度：1080px。
- 宽幅：1360px。
- Root padding：24px。
- 卡片圆角：4px，避免通用 SaaS 的圆形大卡片。
- 图片统一 16:10 裁切。

### 签名元素

使用“工厂标线 + 信号色”语言：

- 页面标题下方有 orange/yellow 双色刻度线。
- 深色面板左侧有信号色边条。
- 按钮是直角 orange 实心块，带 ink 色 offset shadow。
- 表格首行使用 ink 底、mono 字母间距，强化技术参数感。
- body 背景有极淡的 48px 网格。

## 编译器增强

`src/blocks.ts` 的 `catalog` Query Loop 从原来的：

- post title
- post excerpt

改为：

- post featured image
- post title
- post excerpt

这样产品、案例等 CPT 目录可以直接展示图片卡，而不是只有文字列表。

### Cases
