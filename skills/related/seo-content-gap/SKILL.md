# 竞争关键词与内容缺口

先读取 references/seo-api.md 的工具参数与数据口径。本技能为浏览器适配版，来源见 references/seo-sources.md。

1. 确认自家站与竞争站。用 gap 查询 competitor 有排名、target 没有排名的词；工具已固定正确方向，不要交换两个域名。
2. 保留关键词、指标、竞品排名 URL 和来源。过滤无业务相关性的品牌词和无力兑现的服务。
3. 查看自家实际页面清单或相关页面；“没有排名”不是“没有内容”，有对应页优先改进现有页，未确认内容覆盖时称为候选排名缺口。
4. 按业务相关性、需求证据、自然难度、已有覆盖、需要的真实素材安排优先级。缺数据不填零、不产生伪精确评分。
5. 输出 gap-keywords.csv 与 content-plan.md，每条含竞品证据、对应自家页/未知、更新或新建建议、理由和验收方式。仅当前返回样本，不声称穷尽所有缺口。
