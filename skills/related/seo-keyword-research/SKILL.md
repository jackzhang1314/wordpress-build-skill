# 关键词研究与机会筛选

先读取 references/seo-api.md 的工具参数与数据口径。本技能为浏览器适配版，来源见 references/seo-sources.md。

1. 从用户产品资料确定种子词、采购对象和国家语言；产品同义词属于待查询候选，不是已有需求证据。
2. ideas 扩展种子词；对最终候选用 keywords 补充指标。先读已有数据避免重复查询。保留返回字段、月度日期与空值。
3. 将供应商、厂家、批发、规格、应用、比较、教程等词按采购阶段分类。搜索意图先看 API 字段，自己的判断标注为分析。
4. 按业务相关性、搜索需求、自然难度和可提供的差异价值排序，解释取舍。缺难度不计算伪精确机会分数，广告 competition 不替代自然难度。
5. 输出 keywords.csv 和研究说明，包含关键词、市场、量、难度、CPC、意图、建议页面、理由、来源。未返回的词列为未知。
