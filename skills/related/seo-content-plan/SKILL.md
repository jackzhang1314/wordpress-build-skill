# 内容计划与本地化

先按需读取 references/seo-api.md 的实际工具合同，来源与修改说明见 references/seo-sources.md。本技能运行于本浏览器 Agent，不需要终端或 MCP。

1. 读取产品、采购人群和已有页面清单；明确国家与语言、发布周期和可用产能。没有产能约束时提供可调整的建议，不假定团队每天能发布多篇。
2. 使用目标市场关键词和 SERP 样本，区分产品/分类/应用/教程/比较页，不能只把原文词逐字翻译当当地搜索需求。
3. 以主题、采购阶段、业务相关性和可提供的独有事实安排顺序；记录主词、辅助词、意图、页面类型、独有素材、依赖、负责人（未知留空）和拟交付日。
4. 检查一个意图是否被多页抢占，已有页优先更新；本地化标出单位、规格、术语和认证需要业务确认，不生成不存在的当地办公室、客户或认证。
5. 输出 calendar.csv 与 localization-briefs.md；需要文章时按简报生成完整稿，需 WordPress 发布时按参考中的草稿/发布流程执行。批量页面必须有实际差异价值，不机械替换国家名。
