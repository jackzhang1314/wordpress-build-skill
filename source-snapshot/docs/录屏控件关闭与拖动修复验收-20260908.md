# 录屏控件关闭与拖动修复验收

时间：2026-09-08 02:06:08 GMT+8
范围：本次只修复网页录屏浮层的关闭、拖动和位置关系，不扩展区域录制方案。

## 问题与修复

1. 设置原本没有独立关闭入口和拖动事件，面板位置计算可能覆盖工具条。现在提供固定标题栏、拖动把手和右上角关闭；Esc、外部点击、再次点击设置也可收起。设置内容独立滚动。
2. 工具条关闭原本等待后台cancel成功，过期会话被拒绝后界面仍在。现在本地浮层立即关闭，清理监听/计时器并请求取消；后台将无主/旧会话的取消视为幂等成功，不操作其他会话。
3. 准备请求完成较晚时，不重新生成已关闭的浮层；错误提示关闭后，不因相同状态轮询重新弹出。
4. 拖动/窗口缩小后重新约束位置，并让设置与工具条避让。极窄窗口隐藏冗余“录屏”文字，保留操作按钮。

## 验证证据

- typecheck、lint 通过；11 文件 / 56 项录屏专项通过。构建结果见下方日志。验证过程中共享工作区的WordPress文件短暂出现类型错误，后续复查已通过，本任务未修改该文件。
- 真实有界面Chrome运行生产recordingOverlay组件，保留closed Shadow DOM；通过CDP只读获取布局坐标，使用真实鼠标点击/拖动。没有改写布局值使断言通过。
- 1280×800：设置与工具条不重叠；设置从(470,272)拖到(190,112)，工具条也可独立拖动。
- 390×500及320×300：面板/工具条都在视口内、不重叠；设置正文内部滚动，关闭入口始终可见。
- 设置独立关闭、Esc、外部点击、保留选择；没有扩展RPC时关闭工具条，以及启动错误后再次关闭均通过。
- 该浏览器页面是局部UI验收夹具，无媒体采集、无有效扩展RPC；故意使用真实的RPC不可用情况检查退出能力。**本轮未重新验证媒体采集/编码，也未重载用户已安装插件。**后台幂等、旧会话隔离与轮询边界以自动回归验证。
