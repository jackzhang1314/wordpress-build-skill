## 场景组合建议

- “公开联系人与联系入口查找”和“客户产品与我方产品匹配”可作为“一键背调”结果中的深入操作。
- “否词候选与误伤检查”可放在“Google 搜索词质量分类”结果之后。
- “关键词采购意图与页面规划”可与“搜索结果页面类型研究”串联使用。

场景数量不必等于独立入口数量；可按实际工作流程组合，让用户从当前结果继续完成下一步。

## 2026-09-07 用户确认：WordPress 与 SEO 七项实施范围

确认时间：2026-09-07 23:48:43 GMT+8。以下是用户选择的产品范围，不代表新增功能已经实现。

### 架构选择

- 页面采用 WordPress 原生 Gutenberg 区块模式；本轮不做 Elementor、Divi、Bricks 等第三方页面编辑器适配。
- 产品内容使用 ACF 现有自定义内容类型与字段；本轮产品上传路线不采用 WooCommerce。ACF 提供字段模型，页面展示仍需对应模板支持。
- 表单采用 WPForms；SEO 设置采用 Rank Math 已公开且站点实际允许的能力。
- DataForSEO 用于关键词、搜索结果、竞争及监测数据；WordPress 连接器负责内容和站点操作。凭据在连接器统一配置，Skill 按业务场景使用。

| 编号 | 用户选定功能 / Skill 方向 | 输入与交付 | 必要开发与验收 |
| --- | --- | --- | --- |
| WP01 | 原生区块页面创建 | 企业资料 → 产品页、案例页、FAQ、广告落地页草稿与预览 | pages API；受支持核心块的序列化与验证；编辑器可继续编辑且无无效区块；前台桌面/移动端检查。不能以整页 HTML 块冒充原生可编辑区块页面 |
| WP02 | ACF 产品批量上传 | Excel/CSV、图片、字段映射 → 产品草稿与逐条结果表 | 发现已有内容类型/字段/schema/授权；单位、必填项和唯一标识校验；先样本再批量；持久化远端ID防重；缺少展示模板时明确提示，不把数据上传算成页面已展示 |
| WP03 | 图文与媒体上传 | 图片/PDF、文稿 → 媒体ID、图片说明、特色图和正文关联 | 二进制上传；素材复用；alt/caption；featured_media；资源可访问；媒体成功但文章失败时可恢复，避免重复上传 |
| WP04 | 询盘表单搭建 | 业务目标与字段要求 → WPForms 表单及页面嵌入 | 检查版本、写开关和字段schema；创建/更新/回读；采用站点支持的嵌入方式；验证呈现。真实提交与邮件送达属于单独业务验收，不能由表单可见推断 |
| WP05 | 关键词文章生成与发布 | 关键词、国家、语言和企业事实 → 数据依据、文章、WordPress 草稿或发布回执 | 复用 seo-content-studio 与现有发布工具；补媒体、分类等完整交付；真实 DataForSEO→WordPress 链路验收。无需重复新增同名 SEO 写作 Skill |
| WP06 | 站点 SEO 设置修改 | 检查结果与目标 → 可支持设置的修改对比及页面输出核验 | Rank Math 具体能力发现与适配；未开放字段明确列出；写入后回读并检查head。改变全站索引/永久链接等动作单独呈现影响，不默认执行整站一键修复 |
| WP07 | 持续 SEO 监测 | 域名/关键词、市场、频率和次数 → 有时间的数据快照 | 复用现有有限次数监测；验收暂停、次数边界、断线/凭据变化和结果未知。Chrome关闭时不保证执行，不宣称服务器常驻监测或无限监控 |

### 建议实施顺序

1. 站点能力发现与媒体工具：为页面、文章和产品共用。
2. 原生区块页面创建，并完成关键词文章的图文发布闭环。
3. ACF 产品导入：已有模型映射、图片关联、批量结果与前台展示核验。
4. WPForms 表单创建与页面嵌入。
5. Rank Math 支持项修改与回读；联合验证已有 SEO 监测。

验收以实际用户结果为准：原生块可编辑、数据映射正确、图片和表单真实关联、API回读和前台呈现一致。研究依据见 [WordPress 生态与 Skill 扩展研究](research/wordpress-ecosystem-20260907/WordPress生态与Skill扩展研究.html)。后续实施范围以本节用户选择为准，研究报告中的其他14项提案保留为候选，不自动全部开发。
