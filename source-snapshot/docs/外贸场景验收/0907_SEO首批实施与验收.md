## 前端交付

设置 → 技能 → SEO 优化，共九个活动入口：

| 技能 | 交付 | 数据依赖 |
|---|---|---|
| 关键词研究与机会筛选 | 带指标及筛选依据的关键词表 | DataForSEO |
| Google 搜索结果分析 | 当次搜索结果样本与页面建议 | DataForSEO |
| SEO 文章工作室 | 按需求交付简报、大纲或完整文章草稿与来源 | DataForSEO、当前模型、企业事实 |
| 竞品与域名分析 | 域名概况、排名关键词与竞品分析 | DataForSEO |
| 竞争关键词与内容缺口 | 缺口关键词及页面机会 | DataForSEO |
| 关键词聚类与内容地图 | 主题聚类、页面分配与优先级 | DataForSEO、当前模型 |
| 旧文章数据诊断与更新 | 更新依据、建议与文章草稿 | DataForSEO、页面内容 |
| On-page SEO 检查 | 当前页面字段、问题与建议 | 已有浏览器页面检查能力 |
| 技术 SEO 与搜索研究 | 页面与搜索证据范围内的技术诊断 | 已有浏览器能力；不等同全站审计 |

设置 → 连接器 → DataForSEO 统一保存 API Login / API Password；七个数据型技能共用账户。密码不回填到输入框。技能详情可以进入连接器配置，并逐级返回原技能。文章由当前 AI 模型生成，DataForSEO 提供研究数据；没有自动发布 CMS。

## 实现重点

- 原十个数据型原型整合为七个。文章相关三个入口合并为文章工作室，域名与竞品入口合并；保留旧包与历史版本，旧名称解析到新入口，兼容禁用偏好。
- 技能采用稳定名称及显式元数据注册；保留包内方法、参考、许可证与导出能力。
- 七类查询使用固定主机及白名单接口；校验市场、输入和查询范围，沿用现有付费审批和只读约束。
- 先持久化提交状态再发送付费请求，未知结果不自动重复查询；成功结果保存为带来源、时间、费用及覆盖范围的数据文件。
- 回执保存文件版本和内容哈希，复用前核对；处理文件已写入但最终回执保存失败的恢复情况。文件缺失或被改写时停止复用，避免静默重复付费。
- 在 JSON 解析后对字符串递归脱敏，避免凭据恰好为数字时损坏状态码或指标。此机制不替代真实服务联调。

## 验证结果

通过：`npm run typecheck`、`npm run lint`、八个相关测试文件共 88 个测试、`npm run build`。

测试范围：DataForSEO 15 项专门测试，以及技能目录、连接器依赖、设置导航、选择器、技能页面、Apify 回归、工具记录。覆盖凭据更换/删除、HTTP 与业务错误、市场校验、缺口方向、未知提交、文件恢复与缓存完整性等。

浏览器预览验证：SEO 分类显示九个入口；文章工作室显示五个包文件及连接器入口；DataForSEO 显示七个关联技能；授权页显示两个凭据字段；连续返回恢复原文章工作室详情。预览地址：http://127.0.0.1:4178/all-settings?route=skills。
