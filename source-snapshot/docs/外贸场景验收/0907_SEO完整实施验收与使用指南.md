## 3. 前端使用

1. 打开设置 → 技能 → SEO优化；六个筛选按钮按业务场景选择，点击技能查看输入、输出、工作方法、所需连接器及包文件。
2. 设置 → 连接器 → DataForSEO，填写 API专用 Login / Password 并测试。七类基础查询与外链/抓取/性能共用此配置。
3. 设置 → 连接器 → Google。Search Console/Gmail使用Web OAuth Client ID，按页面显示的回调地址在Google Cloud注册；按需授权搜索数据、邮箱或两项。仅CrUX场景可只填启用相应API的API Key。
4. 设置 → 连接器 → WordPress，填写HTTPS站点、用户名、应用密码并测试。文章默认保存草稿，发布参数会供确认。
5. 定时监测通过AI任务说明目标、国家/语言、间隔和次数后确认创建。在DataForSEO详情页查看和暂停计划；任务内用监测状态工具读取每轮文件并生成复盘。
6. 前端预览已构建：`http://127.0.0.1:4178/all-settings?route=skills`。预览不能完成真实Chrome identity授权；真实使用需要在Chrome扩展管理页重新加载本地 `dist` 扩展，再刷新插件页面。本轮新增identity与alarms权限。

示例请求：

- “用DataForSEO研究德国工业阀门关键词，先列市场和查询范围，再给出有来源的机会表。”
- “审计example.com，最多100页，不启用JS；完成后列技术问题和已覆盖范围。”
- “找这两个同行都获得、我方还没有的相关引用域，核实实际来源页，整理联系机会。”
- “根据这些产品事实和关键词生成完整英文文章，先保存WordPress草稿。”
- “每24小时记录一次这个域名在美国市场的排名概况，最多7次；显示整体计划费用授权后创建。”
