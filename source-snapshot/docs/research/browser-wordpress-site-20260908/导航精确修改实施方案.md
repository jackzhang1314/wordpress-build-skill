# 导航精确修改实施方案

2026-09-08，基线f750d05，先研究后实施。

复用wp/v2/template-parts官方接口。新增wpPlanNavigation只读计划、wpApplyNavigation受现有写确认保护，放入wordpress按需工具组。计划写固定版本任务文件，摘要hash记入会话；apply只接受本任务已生成的未篡改计划，复用wpOperations处理未知写与回读恢复。

第一版只支持主题模板部件中的一个确切core/navigation片段：自闭合导航，或仅由navigation-link/page-list自闭合子块组成的简单导航。片段必须唯一匹配原文，已有锁或复杂子结构拒绝。保留区块属性、替换菜单内容；若有ref，移除引用并转为该部件内联导航，明确共享菜单其他使用处不变。保留片段之外所有字节。不替换整个页眉布局，不安装主题，不写PHP。

链接仅来自指定已发布的站内page，最多12项。读取活跃区块主题、部件原文、页面真实URL。应用前重新读取并核对全部依据；客户端检查仍不能提供服务端原子锁。修改共享模板部件会影响引用它的所有页面，计划必须提示。写后核对完整raw内容，浏览器另验实际引用页面。

评估了官方block-serialization-default-parser；它适合整树解析，但本阶段无需完整重序列化树，且无源码片段偏移的公开输出。本阶段只对小型受限导航片段做结构校验和字面替换，不扩建通用WordPress解析器，无新增依赖。复杂导航/嵌套子菜单/模式引用仍走明确不支持，后续再评估官方生态完整适配。

验证：原片段唯一性、复杂/锁定结构拒绝、非导航布局字节保留、已发布页/站内URL、计划绑定、过期停止、未知不重放及回读；真实WordPress默认页眉导航替换、Gutenberg和窄屏交互。
