# 现有WordPress站点检测与适配方案

2026-09-08；先设计后实施。用户主题保持不变，不增加主题包。

升级现有wpReadDesignProfile为统一报告，保持原工具名与读取语义，不新增重复工具。增加账号capabilities、内容类型声明与有界OPTIONS schema读取；已有主题/核心区块/模板/主题样式继续复用。完整响应存任务证据，工具仅返回摘要和适配步骤。

每个内容类型分开判断：端点是否可访问、连接器是否适配namespace、账号是否声明创建/发布权限、正文/ACF/meta字段与模板枚举是否公开、现有写工具是否适配。OPTIONS存在不证明有写权限，角色名称不作为权限判断；capabilities缺失是unknown，不是false。

页/文章默认检查；自动追加最多6个非内部内容类型，允许显式指定最多8个类型。类型名称/rest_base仅接受安全路径段，非wp/v2命名空间报告当前连接器未适配。媒体上传基于upload_files声明，只是尝试资格，不保证上传成功。所有写入仍由原工具、站点权限与回读决定。

适配结果给出：可尝试创建草稿、权限不足、待确认、当前工具未适配。经典主题可继续用原生内容块，不因此要求更换区块主题；没有自有站点插件也不阻止普通建页。ACF字段公开不代表当前模板动态展示，前端检查始终待做。

验收覆盖：有权限原生站点、经典主题、403/缺caps、可见OPTIONS但权限false、现有ACF CPT、未知namespace、无写工具适配、限量扫描、大schema仅保存证据、全程无POST。更新建页Skill，先读报告再产出页面方案；测试types/lint/相关Harness预算/build。真实客户站点整站发布不在本轮伪造完成。

依据：WordPress官方REST Types与Users文档（https://developer.wordpress.org/rest-api/reference/types/ 、https://developer.wordpress.org/rest-api/reference/users/）。本地调用契约与Zod类型以当前源码为准。
