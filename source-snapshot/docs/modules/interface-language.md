## 语言优先级与用户入口

设置首页“浏览与使用”区域提供“界面语言 / Language”，紧邻文字大小。支持 `auto`、`zh-CN`、`en`。默认跟随 `chrome.i18n.getUILanguage()`，中文区域变体统一映射简体中文，其他语言回落英文；非扩展预览使用 `navigator.language`。语言名称使用自称，不用国旗。

界面语言独立立即保存，不调用模型配置保存、验证或数据授权。失败恢复已保存选择；较晚返回的初始读取或旧保存回执不得覆盖更新的存储事件。切换不重新挂载输入框，不改用户草稿、选区、会话正文、自定义动作、提示词内容、术语草稿或网页翻译目标语言。AI 输出语言不是本设置的职责。

## 数据流与存储边界

- `src/i18n/protocol.ts`：语言枚举、独立存储键 `octopus-ui-language-v1`、只读 Port 名 `octopus-ui-language`。
- `runtime.ts`：i18next 26.4.2、本地打包资源、带插值参数检查的 `t()`、自动/手动状态、订阅和 `Intl.NumberFormat`。
- `service.ts`：后台从受保护的 `chrome.storage.local` 只读取语言键，向本扩展的已连接 Port 推送单个枚举值；不接收写入命令，不广播整个设置对象。
- `client.ts`：网页 content script 通过只读 Port 获取偏好，后台断连后以 1—30 秒退避重新订阅；页面卸载释放订阅。
- `dom.ts`：只更新显式绑定的产品文案节点及属性。`data-i18n` 用于静态模板，`bindText`/`bindAttribute` 用于动态文案。保留图标、子控件、事件和焦点；不会按中文字符串扫描或翻译宿主网页、聊天正文和用户内容。
- `preference.ts`：设置控件与保存反馈。界面使用既有蓝色 design token，不按语言复制样式主题。

已有模型配置使用 `TRUSTED_CONTEXTS` 保护整个 local 存储区，不能为语言同步放宽它。content script 从启动开始就走只读通道，避免后台尚未完成保护时可读、之后却失去同步的竞态。此设计依据 Chrome 的 [存储访问级别](https://developer.chrome.com/docs/extensions/reference/api/storage#method-StorageArea-setAccessLevel) 和 [长连接消息](https://developer.chrome.com/docs/extensions/develop/concepts/messaging#connect) 契约。

后台错误路径不依赖当前界面语言，语言切换也不会触发权限申请、注入网页、重新执行任务或付费模型调用。

## 文案、元数据和 token

`catalog.ts` 使用语义键维护中文/英文成对资源；调用方的键名及必填插值参数由 TypeScript 检查。需要参数的条目不能用于无参数静态 HTML 标记。新文案应使用完整句子，避免在代码里拼接语序。

字号、颜色、间距仍由 `src/design` 维护；语言只是内容与格式化维度。英语长标签应允许换行、flex 收缩和容器内滚动，不能通过缩小正文解决溢出。动态内置动作显示名可以翻译，配置中的动作 ID、原始名称、提示词和用户改名不迁移。

原生扩展名称、描述、快捷键说明使用 `public/_locales/en`、`zh_CN`、`zh_TW` 和 manifest 消息引用，默认英文；当前 `zh_TW` 资源仍为简体文案，不是完整繁体支持。构建复制语言目录和 i18next 许可证。浏览器原生扩展元数据跟随浏览器语言，不承诺随应用内手动选项热切换。

## 错误分类与恢复动作

`src/lib/product-error.ts` 将边界异常归一为 `ProductFailure { code, diagnostic }`，RPC 兼容原来的 `error` 字段并增加可选 `failure`。诊断信息限制长度并脱敏，主提示在 UI 根据当前语言生成。未知英文使用通用本地化提示，原始信息放在折叠技术详情；已登记的业务错误按当前语言显示；未知中文及中英混合诊断也收进技术详情。

| 类别 | 主提示与恢复行为 |
| --- | --- |
| `page-activation` | 点击浏览器工具栏插件图标的步骤；不把普通侧栏按钮视作自动取得 activeTab |
| `page-policy` | 明确浏览器策略限制，提供排查办法；不承诺重复点击或刷新解除限制 |
| `page-access` | 打开对应网站权限设置入口 |
| `model-key` | “配置 API Key”直接定位并聚焦密钥设置 |
| `model-data` | 直达任务数据使用说明，用户自行决定是否允许 |
| 网络、超时、限流 | 当前语言说明，保留输入，由用户决定重试 |
| 未知错误 | 简短提示和折叠技术详情，不直接把陌生英文当作主引导 |

`ActionNotice` 与 `settings-guidance-view` 保留带操作的错误直到关闭。设置按钮用稳定目标标识定位，不依赖翻译后的文案。旧中文正则只用于尚未迁移的边界兼容；不能新增靠本地化句子决定权限或执行分支的逻辑。
