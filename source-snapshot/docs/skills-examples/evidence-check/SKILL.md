# 网页证据核对

当用户要求核实当前网页的内容时：

1. 先读取任务网页，确认页面标题和来源地址。
2. 阅读 references/checklist.md，按其中规则确定核对范围。
3. 从页面中提取 3–5 条与用户问题最相关的事实，保留具体数值、单位或原始措辞。
4. 输出“核对项 / 页面证据 / 结论”表格。对于没有提供的信息，写明“页面未提供”。
5. 最后说明本次核对的覆盖范围，并附实际读取的页面来源。不要将单个页面的自述当作独立第三方认证。
