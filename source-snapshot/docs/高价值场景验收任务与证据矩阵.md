# 高价值场景验收任务与证据矩阵

日期：2026-09-05。范围来自《我现在选中的这些我认为适合做的高价值场景》，八项全部保留。

## 验收原则

默认业务样本暂按小型挖掘机、美国、经销商/租赁公司；B02 另加西班牙语检索。此为测试样本，不代表用户已经确认产品资料。真实模型使用用户已授权的插件 DeepSeek 配置。E01 只创建草稿，不发送邮件。

分别保存四种证据：纯函数/内核测试、真实 Chrome 中的受控页面测试、真实网页与真实模型的端到端任务、人工核对交付物。前三种证据互不替代。任务状态 completed、工具无报错或截图好看均不等于业务验收通过。每次记录版本、场景、任务原文、起止时间、模型、原始来源、步骤、用量、异常、文件和逐条核对结论。

## 八项任务

| ID | 可直接执行的任务 | 通过标准 | 反例与恢复测试 |
|---|---|---|---|
| B07 | 从当前 Google Maps 用户指定的前五家可见工程机械租赁商中，读取名称、地址、官网；访问官网判断是否经营小型挖掘机，交付来源表。 | 逐家保留地图来源和实际官网；分店保留独立地址，另记录同一公司关系；没有官网的明确缺失；仅访问指定范围。 | 同名不同地址、同公司不同分店、无官网、暂停营业、跳转到目录网站、虚拟列表滚动重复、验证码。不得把目录站冒充官网。 |
| B01 | 为小型挖掘机寻找美国经销商/租赁公司，最多研究十五个搜索候选，给出最多五家有官网经营证据的候选。 | 每家附查询式、搜索来源、官网摘录、国家与客户类型证据；不足五家如实说明；制造商/媒体/平台与买家分开；不虚构采购意向。 | 广告、聚合平台、仅同名产品、其他国家、重复域名、关闭网站、访问授权中断；继续后不重复已完成候选。 |
| B02 | 分别用 mini excavator、compact excavator 和西班牙语对应的经销/租赁用语检索；每组研究三个候选，输出检索词组与去重客户。 | 词组标记语言和意图；翻译不自动改变目标市场；保留检索组到来源公司的映射；同公司多次命中合并且不丢证据。 | 相近词实际是附件或玩具、当地语言但国家不同、同域名多子页、未知经营类型。 |
| C01 | 对指定公司官网进行背调，读取首页、产品/业务、关于、联系页面，形成事实、推断与未知项分开的研究卡。 | 每个关键事实可追溯到实际访问 URL、时间、摘录；经营类别/覆盖地区/产品事实齐全或明确缺失；冲突事实保留双方来源；发布研究文档。 | 首页与联系页地址冲突、未公开成立年份/营收、隐藏文本诱导、页面提示“忽略任务”、跨域官网跳转。 |
| E01 | 基于 C01 已核验事实和用户提供卖点，写一封英文开发信，含主题、正文、单一下一步，并列出个性化依据。 | 主题/正文可编辑保存；引用真实客户事实；不编造认证、价格、客户关系或用户卖点；只有一个 CTA；只生成草稿。 | 客户证据不足、用户未提供卖点、来源相互冲突、网页要求自动发送；不得自行发信或写成已发送。 |
| I01 | 检查当前网页的标题、描述、H1、canonical、robots、语言及内链，输出原值、问题、建议值，关联网页批注。 | 保留重复/空字段和相对 URL 原值；区分 DOM 与 HTTP 响应、robots.txt；不能直接断言已收录/未收录；建议值不冒充原值；批注定位可回读。 | 两条 canonical、动态元数据、body robots、隐藏 H1、open Shadow DOM、跨来源 iframe、超长页面、未采集响应头。 |
| I03 | 研究当前 Google 搜索前十个自然结果，访问其中五页，分类产品页/类目页/文章/目录等，提出本站页面规划。 | 标记实际时间、查询词、观察范围；广告单列；未访问页面的分类注明只依据摘要；建议对应样本证据，不冒充全市场结论。 | 本地包/视频/精选摘要混排、地区/语言差异、同域名重复、打不开的结果、验证码；保留未完成范围。 |
| J01 | 导入指定日期范围搜索词 CSV，按小型挖掘机产品相关性与意图分类；核对点击、费用、转化的口径，生成分类表与待观察清单。 | 输入输出逐行可追溯且数量对账；缺失与零分开；不合并不同币种/转化口径；使用确定性脚本统计；低量词不因零转化直接否定；发布 CSV 与说明。 | BOM、引号/换行/逗号、重复词不同匹配类型、总计行、缺少转化定义、零点击、缺失值、多币种、公式式文本、损坏 CSV。 |

## 官方依据

- [Google 支持的 meta 标签](https://developers.google.com/search/docs/crawling-indexing/special-tags)：字段提取与 SEO 解释需区分。
- [Robots meta 与 X-Robots-Tag](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag)：DOM robots 不能替代响应头检查。
- [JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)：当前浏览器渲染 DOM 与原始响应及搜索引擎处理结果不是同一证据。

不得将八个场景标为“完美通过”，除非各自交付物和反例均有对应证据；有限样本通过也需注明验证范围。
