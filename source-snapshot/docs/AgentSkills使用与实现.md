# Agent Skills：使用与实现

版本：0.5.0。内核：AI SDK ToolLoopAgent。本功能在插件内加载 Skill，不使用供应商 uploadSkill。

## 从哪里使用

重新加载 Chrome 扩展并关闭重开侧栏。输入框底部的“技能”可以打开技能库：

- 点击“使用”，在草稿光标处插入行内技能卡片，继续输入任务并发送。底层保留稳定技能引用；手动输入 `/技能名称` 仍兼容。
- 不指定技能时，模型依据启用技能的名称与描述自行判断是否加载；普通问题无需加载技能。
- 执行期间选择技能后发送的消息仍先排队；点击“调整方向”时，该消息和对应技能一起生效。
- 执行记录显示“使用技能”“读取技能资料”，任务完成后随过程折叠，最终回答保持可见。

默认提供 page-table（网页数据整理）、product-compare（产品对比）、site-outline（网站结构）、annotation-tasks（批注转清单）。批注技能需要在发送前勾选“附带批注”。

## 导入自定义 Skill

“上传文件 / ZIP”接受单个 SKILL.md 或 ZIP；“导入文件夹”接受包含 SKILL.md 和参考资料的目录。先预览正文、文件列表与环境要求，再点击“导入并启用”。同名自定义技能显示“更新此技能”，后端核对被替换的版本；内置技能不能被覆盖，可以停用。

SKILL.md 使用标准 YAML 元数据与 Markdown 正文。目录中的 references、assets、scripts 会保留。相对资源通过 readSkillFile 读取，支持分段读取长 UTF-8 文本；不会把所有参考文件一起发给模型。示例包在 output/evidence-check-skill.zip，源码在 docs/skills-examples/evidence-check。

限制是本产品的运行范围，不是 Agent Skills 规范强制值：每包最多 64 文件 / 2 MB、正文最多 16000 字符；同时激活最多 4 个技能 / 24000 正文字数；自定义技能最多 50 个。单次参考读取最多 8000 字符，返回下一段位置。技能版本归档最多 32 MB，删除技能库入口保留历史版本。一次请求的指令及消息另设 140000 字符保护阈值，达到后明确停止而不是截断技能正文。

## 从 GitHub 链接导入

技能库 → **从 GitHub 导入** → 粘贴链接 → **查找技能** → **预览技能** → **导入并启用**。

支持公开 github.com 仓库主页、`/tree/分支或标签/技能目录`、`/blob/分支或标签/技能目录/SKILL.md`，以及固定提交链接。支持带斜杠的分支名称。仓库包含多个技能时逐个列出，可以返回搜索结果继续选择；不会自动安装整个仓库。上传 ZIP 则应包含一个 Skill，多个 Skill 请分别上传。

首次查询由 Chrome 请求连接 api.github.com 的权限。查询只读取目录，选择后才下载该技能的完整包；GitHub 来源、目录与固定提交可在详情中查看。同名技能通过预览后更新，历史任务继续保留旧版本。不会自动追踪上游更新；再次导入分支链接可以检查新内容。

目前不支持私有仓库认证和 GitHub Enterprise。GitHub 限流时可稍后重试或上传 ZIP；超大、被截断的目录会明确报错，建议改用更具体的技能文件夹链接。含符号链接或子模块的包要求换成实际文件。所有下载仅访问 GitHub API，不携带模型 Key 或登录 Cookie。下载时可点击“取消读取”。

格式依据是 [Agent Skills 标准](https://agentskills.io/specification)，仓库读取依据 [GitHub Git Trees API](https://docs.github.com/en/rest/git/trees) 和 [Git Blobs API](https://docs.github.com/en/rest/git/blobs)。GitHub 是分发入口，Skill 的格式由 Agent Skills 规范定义。

## 兼容性说明

支持 name/description、license、compatibility、metadata 的解析和额外字段保留。name 格式严格校验；目录名不一致时允许导入并提示。YAML 使用 core schema，重复键和别名展开拒绝。实验性 allowed-tools 被保存并提示，但当前不自动配置工具权限；其他客户端的专属执行扩展不自动生效。

脚本可保存、查看和作为文本读取。同步 JavaScript 可复制到任务工作区，用 runJavaScript 在隔离沙盒运行；不自动运行导入包，不支持 Python、Bash、Node.js/npm。详见 [文件与沙盒](Agent文件工作区与代码沙盒.md)。二进制资源保存但不能传给当前文本模型读取。环境要求通过 diagnostics 展示，不能仅凭格式正确就认定所有第三方技能均可执行。Skill 不扩大 Chrome 网站权限、任务分组范围或网页写操作权限。

## 内核机制

- src/agent/skills/import.ts：标准包解析、元数据诊断、ZIP 与文件夹导入、路径和体积校验。
- github.ts：公开仓库链接解析、固定版本发现、候选技能隔离与有界下载。
- store.ts：独立 IndexedDB 的技能目录与不可变版本；预置与自定义使用同一接口。
- runtime.ts：名称/描述目录、loadSkill 激活、readSkillFile 资源读取和上下文预算。
- src/agent/runtime.ts：与现有工具串行执行、取消和持久化结合；prepareStep 每次加入一份完整活跃技能说明。loadSkill 工具结果只保留版本、路径和诊断，不再复制正文到普通历史工具结果中。
- StoredConversation.skills 保存活跃技能快照和待激活请求。队列条目保存显式技能引用及版本；出队时才激活，暂停后保留引用。读取途中收到引导也能收尾并转向。
- 库修改只允许在当前任务结束或停止后进行；启用同名新版本不会替换暂停任务中的旧正文。停用/删除后在恢复时过滤活跃技能；队列若仍指定不可用技能会明确报错，可重新启用/导入或新建对话。

SkillRuntime 的渐进式披露是模型上下文策略；消息过程折叠是 UI 行为，两者独立。

## 验证范围

正式实现测试覆盖包解析、ZIP 膨胀限制、版本更新、同名冲突、队列引用、三级披露、上下文保护、实际三种适配器的 HTTP schema 序列化、存储恢复、排队/引导/暂停、加载期间引导、管理界面安全文本展示。

独立 Chrome 原生侧栏验证 ZIP 导入、预览安装、自动加载、参考读取、真实 DOM 填写与点击确认、最终折叠、重开侧栏、技能库持久化与手动选择。原分组/权限/结果复制及队列拖动回归通过。测试使用模拟模型响应和虚拟 Key，未使用用户的真实模型账户；真实模型选择 Skill 的质量仍需要用户实际任务验证。


0.4.1 增量验收：真实公开 GitHub 仓库读取和原生侧栏导入完成，ZIP 上传与重载后技能持久化通过；360px 窄侧栏无横向溢出。浏览器测试副本预授予 GitHub 主机权限；权限拒绝、取消/重开、多技能隔离、截断目录、带斜杠分支、422 回退及来源存储另有自动化回归。没有用真实模型调用评测第三方技能的执行质量。
