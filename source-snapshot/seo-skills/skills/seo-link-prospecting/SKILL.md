# 外链机会发现

先按需读取 references/seo-api.md 的实际工具合同，来源与修改说明见 references/seo-sources.md。本技能运行于本浏览器 Agent，不需要终端或 MCP。

1. 明确我方值得引用的内容、产品资料或行业资产，不能把所有同业来源都视为可开发对象。
2. linkGap 的 target 是我方，competitors 为同行；结果是链接到所选同行的引用域交集，排除我方。需要并集时分组查询并按域名去重。用 backlinks 或 contentDiscovery 获取实际候选页面。
3. 在任务浏览器访问候选页，核查主题、引用上下文、已有目标、站点编辑/合作入口；已失效/不相关/登录阻塞分别记录。公开联系信息必须来自实际页面，不猜邮箱。
4. 分类资源页补充、过期链接替代、原创资料引用、合作案例与媒体询问；每条写我方可提供的具体价值，不做自动灌水、批量评论或虚假身份。
5. 输出 prospects.csv，列域名、来源页、原引用目标、相关性证据、机会类型、我方资产、联系来源、状态、下一步。发现机会不是获得外链，只有现场链接证据才算上线。
