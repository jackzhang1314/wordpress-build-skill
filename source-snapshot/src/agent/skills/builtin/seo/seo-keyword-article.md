# 关键词驱动 SEO 文章

先读取 references/seo-api.md 的工具参数与数据口径。本技能为浏览器适配版，来源见 references/seo-sources.md。

1. 用户给定关键词后以 keywords 查询指标、serp 查询结果；主词或市场缺失时先补齐这两个决定查询的问题。
2. 识别信息、商业比较或交易意图，选择文章、比较页或产品页形式。SERP 以产品页为主时说明普通博客可能不匹配，按用户目标选适当形式。
3. 结合真实企业资料与已读取竞品页面，写出大纲和独特价值，再直接完成用户要求的全文。不要停在“可以写”或只交付提纲。
4. 自然安排关键词、解释术语、用规格/应用/选择步骤服务采购者；标题、图片 alt 和内链描述实际内容，不机械重复词，不虚构图片或页面 URL。
5. 交付 article.md、metadata.json、sources.md，检查事实引用、结构、意图、内链和行动入口。资料缺失明确占位，不能称为已发布或保证排名。
