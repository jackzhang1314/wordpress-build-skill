# 旧文章数据诊断与更新

先读取 references/seo-api.md 的工具参数与数据口径。本技能为浏览器适配版，来源见 references/seo-sources.md。

1. 读取原文和已有证据，记录来源版本。若用户给出历史报表，先核对市场、时间窗口和统计指标；无历史数据不能推断流量下降。
2. 用 keywords、serp 补充当前目标词需求和搜索结果，读取有代表性的页面；基于事实区分过时信息、意图变化和新增问题。
3. 制定保留、修改、补充清单，优先局部更新。不能把竞争文章字数乘倍数当目标，也不凭文章日期断言内容失效。
4. 写出完整更新稿或用户指定段落，保留仍准确的规格、链接和品牌表达；失效数字需要新来源，否则标为待确认。
5. 保存 refreshed-article.md、changes.md、sources.md，列原文证据、修改理由与未验证项。用户未要求发布时仅交付文件，不改 CMS。
