# 数据驱动 SEO 文章

先读取 references/seo-api.md 的工具参数与数据口径。本技能为浏览器适配版，来源见 references/seo-sources.md。

1. 先读用户数据文件与口径，明确统计范围、单位、时间、缺失项。用确定性工具计算，保留原文件，不能从截断预览计算总计。
2. 以主题调用 ideas 或 keywords 验证需求，再用 serp 选择适合的页面类型。用户已有本任务数据时直接复用。
3. 建立论点—数据—原始出处表。搜索量只是需求证据，不能写成市场规模、销量、用户调研结论或本企业业绩。
4. 形成简短提纲后完成全文。围绕数据能证明的结论解释方法与局限，结合企业可核验产品信息；不复制竞品文句，不补造案例、认证、作者经历和统计数字。
5. 交付 article.md、metadata.json、sources.md。元信息含 title、description、slug 建议与待核验项；文章用目标语言，引用紧邻事实。发布前状态为草稿。
