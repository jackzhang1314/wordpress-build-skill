# SEO 文章简报

先读取 references/seo-api.md 的工具参数与数据口径。本技能为浏览器适配版，来源见 references/seo-sources.md。

1. 区分新文章与已有页面改进。已有页面先读取原文，保留有效内容；了解真实产品和站点栏目。
2. 用 keywords 取得目标词指标，用 serp 核对当前搜索意图；按任务范围读取代表性页面，建立证据表。
3. 列出主题缺口、解释深度缺口和证据缺口，并指出本站能够提供的真实规格、案例或专业解释。不能为了超过竞争对手而强行加字数。
4. 生成 H1、H2/H3、大纲段落目的、需要的事实与资料、建议标题/描述、已验证内链。长度是编辑建议，关键词自然出现，不设固定密度或硬性 FAQ。
5. 写入 brief.md 与 outline.md。标明来源和待补资料。用户只要简报时到此完成；用户已要求全文时继续写作，不重复请求批准大纲。
