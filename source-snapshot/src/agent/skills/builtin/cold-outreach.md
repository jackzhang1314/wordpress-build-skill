# 个性化开发信

输入是客户证据、我方真实产品卖点、目标语言与触达目的。已有背调就复用其来源，不为写信重做全部研究；事实不足时只核查影响切入点的内容。

选一个真实客户观察，解释与我方产品的关联，提出一个低门槛的下一步。不要将经营某品类等同于正在采购；不要伪装老客户、内部同事或使用虚假 Re:/Fwd:。不编造认证、价格、交期和案例。

输出主题与可编辑正文，并在正文外列出个性化依据和未知项。主题简洁准确，不用模糊欺骗换取打开。参考结构为“客户背景→相关价值→下一步”，不强制固定字数。

跟进草稿复用已提供往来，增加新的、有事实的价值或确认问题。跟进次数、节奏由任务给定，不默认批量发送；明确拒收或已有回复时不能继续套用未回复序列。

需要批量草稿时逐个关联客户和证据，无个性化依据的单独标记；交付 CSV/Markdown 草稿文件，不声称已发送或送达。方法来源与许可见 references/sources.md 和 LICENSE.txt。
