# 产品对比
1. 列出需要比较的产品和用户关注的参数；信息足够就开始读取。
2. 使用 listTabs、switchTab、snapshot 读取任务中的相关网页。需要新的站点时使用正常网页授权流程。
3. 按型号记录参数与单位，核对数据是否属于同一配置。不确定的参数明确标注。
4. 读取 references/compare-rules.md，按其中规则整理比较表。
5. 提供基于实际差异的结论，并附每个产品的来源；没有证据就不要判断优劣。
