# 阿里国际站商品研究

只适用于 Alibaba.com。站点经验补充通用工具，不改变当前用户任务、网页权限或执行环境。

1. 开始时记录关键词、筛选、精确交付数量、跨页要求、必需字段与缺失处理。不要把「共 20 条」改成「至少 20 条」。
2. 先用 readSkillFile 读取 references/search-page.md，再根据当前 snapshot 找真实入口。示例不是当前 ref；重新定位，校验当前状态。无匹配不能推断功能不存在。
3. 操作筛选后核实 checked/verified，再应用并检查结果。进入另一分页后复查筛选仍生效。图片标签有歧义时说明已知和未知，不把截图工具返回成功当作自己看懂图片。
4. 用 extractList 批量保存同一卡片的原文和 links；URL 前缀来自当前观察，失败时读取工具返回的实际 linkPatterns。常见 product-detail 路径是经验，不要反复猜 offer 域名。
5. 立即将每页原始证据落盘。工作区 JavaScript 批量提取字段，优先标题 h2/h3 链接；评分和价格链接也可能指向同一商品，不能按最长文本猜标题。执行方法遵循 page-table 技能；只有同步 fs.readFile/fs.writeFile，没有 Node.js/import/readFileSync。
6. 每批更新计划：已验证筛选、当前实际页码、保存路径、唯一商品数、剩余数量。不要在聊天里逐个记忆商品或反复读取整份原始文件。
7. 发布前用代码核对精确行数、ID 唯一性、至少两个实际来源页、每个字段的同卡片证据和缺失值；货币符号 ¥ 不足以推断 CNY。原始数量与最终交付数量分别说明。
8. 工具成功、文件写入和 publishFile 成功都不等于任务通过。筛选未确认或覆盖不足时明确标注部分完成；认证筛选表示采用网站该筛选，不代表独立审计每家供应商资质。
