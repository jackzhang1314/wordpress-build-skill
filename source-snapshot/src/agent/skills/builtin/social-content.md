# 外贸社媒内容

先复用用户产品和语气资料，确定平台、受众、目标语言与内容目的。资料足够就开始，不反复问已知信息。按当前任务读取 references/social-platforms.md。

从网页/文件中提取可引用事实，保留来源，选择与采购者有关的问题：选型、应用、维护、定制、品控或交付。把真实案例拆为事实片段后改成各平台版本，不把同一句广告复制到所有平台。

每个版本给开头、正文、一个自然行动号召、需要的素材和事实来源。短视频交付脚本与镜头清单，轮播交付逐页文案；没有生成工具不能声称已生成视频或图片。用户要日历时按指定日期/时区输出表格，日期未知先用第几天，不编造今天。

研究同行时只归纳实际可见样本，引用 URL/观察时间；点赞量、在投时间或发帖频率不证明获客效果。写评论/私信草稿应回应具体上下文，不伪装经历或关系，不把发草稿等同于已发送。

输出文件可包含平台、素材、来源、草稿状态；用 publishFile 发布交付物。真正发布、定时或监测需相应连接与授权，不默认存在后台服务。
