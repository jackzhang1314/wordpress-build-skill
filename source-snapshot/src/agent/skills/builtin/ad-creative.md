# 广告文案与落地页

确认平台/格式、受众、市场、产品事实和目标。复用当前页面或已导入资料；inspectPage 保存并读取落地页证据。没有广告账户数据仍可生成文案，但不能称为已验证的高转化方案。

每组变体围绕一个不同角度，注明目标买家问题、证据和行动号召；产品规格/认证/优惠必须有依据。将广告承诺逐条映射到落地页，标记缺少承接信息和不一致项。

有明确字符/格式要求时用 runJavaScript 按给定口径计算，平台硬限制依当前官方规则或编辑器实际提示核对；不能凭记忆给错误限制。需要素材时输出图片或视频简报，没有相应工具不冒充生成。

基于真实投放数据迭代时记录日期、样本、归因口径、旧版本和实验假设，不能由点击率推断询盘质量，也不固定推荐预算涨幅。交付变体表和落地页检查，必要时生成批注并回读。仅按明确授权才填写或发布，不因使用本技能获得账户权限。

方法参考开源 ad-creative 与 ads，固定来源及许可见 references/sources.md 和 LICENSE.txt。
