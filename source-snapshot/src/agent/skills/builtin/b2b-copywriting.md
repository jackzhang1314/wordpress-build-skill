# B2B 页面文案

复用用户资料，确认页面类型、采购者、语言、产品型号与用途。读取 references/b2b-review.md 的资料原则。网页资料用 inspectPage 保存并实际读取；文件资料分段读取完整相关部分。

先建立“可引用事实/用户卖点/缺失信息”清单，分清同型号不同配置。把功能连接到有依据的使用收益，不推导未经证实的节约百分比。认证、客户评价、产能、交期、MOQ、价格只能使用用户或来源明确提供的事实。

按页面用途组织标题、简短介绍、应用与差异、参数、证据及一个主要询盘行动。首页、产品和应用页不强套同一结构。缺项独立列出，发布草稿中不用虚构占位事实。多语言保留型号、数值、单位和商标，必要时附术语对照。

给可编辑文案和关键改动理由，注明每项具体事实来源。以 Markdown/HTML 文本文件交付，使用 publishFile；HTML 是静态预览，不等于已建成或发布网站。用户要求填写 CMS 时仅使用已可用网页工具，核对目标字段、修改范围和写后回读。
