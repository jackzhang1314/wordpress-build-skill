# 外贸询盘转化检查

先复用企业资料，确认目标客户、页面目标与流量背景。未提供广告时不假定广告承诺。阅读 references/b2b-review.md 中的采购路径判定。

用 snapshot 和 inspectPage 保存页面证据并读取正文。需要视觉判断且模型支持时使用 screenshot，区分看见的布局与 DOM 属性。观察首屏是否说明供应什么、供谁使用，以及产品参数、应用、制造与品控证据是否支持采购决策。

按“采购问题→当前内容→缺口→建议→页面位置→验证方法”整理。把事实错误、表达问题与实验假设分开。没有转化数据就不声称页面流失率或提升幅度。不要机械删除 MOQ/规格字段或导航；解释它们对询盘质量和填写成本的取舍。

表单先检查可见字段、必填、错误提示和联系路径；不为了审计提交真实询盘。建议文案不得增加未经确认的认证、优惠、交期或价格。用户要求保存时用 createAnnotation 与 readTaskAnnotation 记录实际编号；不可定位项进入报告。

交付页面修改清单，优先说明具体问题和依据。复查时重新访问并核对原建议，区分临时样式、已保存内容和已发布页面。
