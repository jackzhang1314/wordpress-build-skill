# 外贸页面采购路径

围绕用户真实客户逐项取舍：买家能否判断产品适用、配置是否匹配、供应商是否有事实证明、询价时要提供什么、提交后预期怎样联系。制造商、品牌、经销商和工程客户关注点不同。

产品页优先保持型号、规格、应用、可供选择及询盘动作的对应；案例需要问题、实际方案和有证据的结果；品牌可信度来自可核查材料，不用虚构徽章或客户 Logo。资料不足时能先改表达，但将新增商业承诺留待确认。

区分三类交付：纠正已有矛盾；补充真实资料；待验证的结构或文案实验。不能凭页面主观评分推断真实转化率。表单字段的减少可能降低线索质量，判断应考虑后续选型需要。

方法参考 Corey Haines cro/copywriting 的页面目标与事实表达原则，已改为本产品浏览器流程；来源与许可见 references/sources.md 和 LICENSE.txt。
