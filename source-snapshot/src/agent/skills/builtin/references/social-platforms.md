# 平台内容适配

LinkedIn：用买家问题、行业经验或有事实的案例切入；论点后给具体依据，避免无内容的公司宣传。
Facebook：说明产品用途、场景和联系理由；适合结合实际图片，语气与目标受众一致。
Instagram：先确认可用视觉素材；文字配合图片/轮播解释应用，不把文字草稿称为视觉成品。

以上为写作建议，不是算法或流量承诺。字符、格式和上传限制变化时核对当前平台页面/官方规则；没有核验就不把旧数字当硬性规范。标签和频率依据用户品牌与资源选择，不强制每天固定数量。

互动任务读取实际帖子与当前评论；区分公开信息和推断的需求。日历优先覆盖不同买家问题，不以填满格子为目标。来源不足可输出选题及待补素材。
