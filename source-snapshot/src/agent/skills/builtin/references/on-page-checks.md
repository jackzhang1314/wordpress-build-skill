# On-page SEO 判定参考

- 标题：描述准确、页面独有、语言一致、避免重复堆词。可以提示过长可能截断，不能把 60 字符当 Google 硬上限。
- 描述：概括实际内容和采购价值；搜索摘要可能取自正文。缺少描述是待优化项，不等于无法排名。
- 标题层级：主标题清晰、阅读顺序合理，区分可访问性问题与排名推测。多个 H1 不自动等于处罚。
- 正文：依据产品/分类/应用页面用途检查采购问题覆盖。没有统一字数或关键词密度目标；产品参数保持型号、单位和配置对应。
- 图片：根据图片用途判断说明需求，装饰图片可用空 alt。inspectPage 的 hasAltAttribute 区分缺少属性与明确空值；旧证据没有这个字段时保持未知。截图中的文字不证明真实 alt 属性；不得因截图看不到就判缺失。loaded=false 可能是未加载或解码未完成，不能单独判定链接损坏。
- 内链：锚文本应帮助理解目标页，推荐关联产品、应用与选型资料。未访问链接不能判断死链，单页未链接不证明全站孤立。
- 技术字段：canonical 是信号，不证明 Google 采用；robots 抓取与 noindex 索引分开；有效结构化数据也不保证富结果。
- 比较：只对已访问和可读取范围下结论，保留来源时间。没有 GSC/报表就不推断流量下降原因或提升百分比。
