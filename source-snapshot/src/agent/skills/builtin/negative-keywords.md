# 否词与误伤检查

先取得已分类搜索词/否词候选、我方产品范围、国家语言、匹配类型及品牌保护规则。未提供业务边界时可列需确认项，不自动将 parts、repair、used 等词认作无效。

CSV 使用 readTableFile 分批读取并核对来源版本/记录范围；统计或导出使用确定性 JavaScript，不从截断摘要计算。逐条保留原搜索词、候选否词、建议匹配类型、理由和可能误伤的有效查询。

区分明确不相关、条件不匹配、需确认与保留观察。低转化/短期无转化不自动等于无效；检查成本、数量、日期与转化滞后。缺数据不能写成零。广泛/词组/完全否定对查询的影响应按当前平台规则或用户提供的准确规则核对；未核验就标记待确认，不冒充平台模拟器。

检查品牌、长尾规格、复数/语言变体和配件业务，禁止将只匹配一个无效查询的短词直接推广成全账户通用否词。给可导出的复核表，未经格式验证不要声称能直接导入平台。采用与账户写入是后续独立动作。

方法参考 ads 的证据覆盖、范围与统计口径原则，来源与许可见 references/sources.md 和 LICENSE.txt。
