# WordPress站点能力插件

浏览器扩展提供连接器和场景Skill，使用用户已有主题。扩展不捆绑、安装或切换WordPress主题。

普通原生区块建页不要求安装本配套插件。需要预设产品/案例模型时，可在「设置→连接器→WordPress」下载Octopus Site插件ZIP，在WordPress后台安装并启用。已有CPT/ACF模型优先沿用。

插件注册oct_product/oct_case及业务字段，ACF可编辑同一份字段；未装ACF时有原生字段表单。字段的前端展示由用户模板决定，需实际检查绑定，不能把字段保存成功当展示成功。站点配置接口仅支持标题、描述、已发布首页和文章页，不提供主题切换或自有主题品牌设置。

用户不需要Codex、Node或本地服务。域名、主机和复杂定制另行处理。

原theme/目录仅保留为此前实验源码，不参与产品构建或安装流程，不代表当前产品路线。旧主题相关验收是历史证据。

开发构建：build.mjs只生成能力插件ZIP。tests/run-playground.mjs验证正式插件ZIP及既有主题保持不变，不安装主题。
